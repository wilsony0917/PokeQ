# PokeQ v4.3

Based on the v4 interface.

Changes:
- PokeQ title/version and Pokémon artwork remain in the gray sidebar.
- Quick Move and Main Move are above Search Results.
- Search Results width is limited to the same left area as Quick + Main.
- Search Results removes the `quick` and `main` columns.
- Type matchup occupies the right column and is tall enough to show all 18 rows without vertical scrolling.
- Search result table remains clickable.
